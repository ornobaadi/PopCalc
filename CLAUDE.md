## Project at a glance

PopCalc — offline, Android-first Flutter calculator with extruded 3D numerals, tactile motion, sounds and haptics. No ads, no account, no data collected. Package `com.ornobaadi.popcalc` (debug/profile get `.dev` suffix and label "PopCalc Dev"). Dart SDK `^3.13.4`, so Dart 3 syntax is used freely (null-aware elements `?x`, wildcard params `(_, _)`, records, switch expressions).

- **Version**: `pubspec.yaml` `version: 1.6.0+17` (last on Play: 1.5.1 build 15; 1.5.5+16 and 1.4.1 were never published; 1.5.1+14 was uploaded but never released). Must be repeated by hand in `_SignatureFooter._appVersion` (`'1.6.0'` — **version name only, never the build number**; `lib/features/settings/presentation/settings_sheet.dart`), `README.md` and a new entry at the top of `RELEASE_NOTES.md`.
- **Portrait-only, except scientific mode**, which may rotate to landscape (see [Orientation](#orientation)). The converter, splash, store and history are portrait.
- **Skins**: 3 free (Marigold, Charcoal, Blueprint) + 3 premium skins (Matcha, Frost, Velvet) + 5 "materials" (Chrome, Glass, Wood, Neon, Mechanical; premium; look + sound + haptics as one set) + 2 limited drops (Mirage, Reckoning) + 1 secret skin (Newsprint, found not bought); 4 more `AppThemeMode` slots (Obsidian, Synthwave, Clay, Candy) are retired and kept only so saved theme numbers still line up. Premium ones are one-time Google Play products, plus an "everything" bundle.
- **Test status** (2026-10-15): `flutter test` → 275 tests, all pass (2026-10-27).
- Docs at repo root: `PRD.md`, `design.md`, `architecture.md` (plan, unreliable), `phases.md`, `README.md`, `RELEASE_NOTES.md` (user-facing notes + Play "What's new" ≤500 chars per release), `docs/privacy-policy.html`.

## App startup flow

`main()` → `WidgetsFlutterBinding.ensureInitialized` → `FlutterNativeSplash.preserve` → `SettingsNotifier.initAudio()` (reads prefs, `AppSounds.init`, **1.5 s timeout** so audio can never block launch) → lock portrait → `SystemUiMode.edgeToEdge` + transparent system bars → `runApp(ProviderScope(PopCalcApp))`.

`PopCalcApp` (ConsumerWidget): watches `themeProvider`; calls `applyMaterialFeel(ref.watch(materialFeelProvider))` **inside build** (side effect on every rebuild, idempotent); `ref.listen`s purchases and theme to `keepToOwnedSkin()` — if purchases are `loaded` and the active skin is not owned, `setTheme(AppThemeMode.sunny)` (Marigold). Watching `purchasesProvider` here is also what starts the store at launch. `builder` wraps in `AnnotatedRegion<SystemUiOverlayStyle>` so status/nav icon brightness follows `colors.isDark`. Home is `SplashScreen`.

`SplashScreen` **continues Android's launch screen**. `main()` calls `FlutterNativeSplash.preserve`, and `SettingsNotifier.initAudio` reads the saved icon into the static `SettingsNotifier.bootAppIcon` before `runApp`. The splash precaches that icon's preview, then `_begin` (`FlutterNativeSplash.remove()`, `AppSounds.launch()`, 1500 ms animation); an 800 ms `_patience` AnimationController (not a Timer, so tests tear down cleanly) begins anyway if decoding is slow. Frame one = Android 12's picture: background `SplashScreen.background(platformBrightness)` (#141414 / #FFAE00, the device's setting, not the skin) and the icon as a 160 dp circle dead centre. Then 22–62 % it shrinks to a 96 dp rounded tile and lifts 30 px; the "POP CALC" wordmark (Antonio w700) arrives at 45–90 %. Then `_goHome`: re-lock portrait, `pushReplacement` to `CalculatorScreen` with a 420 ms fade. Classic uses `assets/app_icons/classic.png` too; the old `pop_calc_mark_*` PNGs are no longer bundled. Native splash: `flutter_native_splash.yaml`, **colour only and deliberately no image** (#FFAE00 light / #141414 dark; follows the device). With no image, Android 12+ draws the icon of the launcher alias the user tapped, i.e. **their chosen app icon**, which `SplashScreen` then continues. Before Android 12 it is just the colour. (History: a fixed logo flashed the official mark before a chosen icon, and a transparent image gave a blank black screen; the owner rejected both.) `flutter_native_splash` is a runtime dependency (`preserve`/`remove`).

## Math engine (`lib/core/engine/`, pure Dart)

Pipeline: `Expression` (immutable) → `Parser` → AST → `Evaluator` → `Decimal` → `NumberFormatter`. Errors are `CalcError` (`calc_error.dart`): `divideByZero` (`5÷0`, `0^-1`), `zeroByZero` (`0÷0`), `overflow` (past 1000 digits, `n!` with n > 450, double ∞), `negativeRoot` (`√(-4)`, negative base to a fractional power), `badLog` (`ln`/`log` of ≤ 0), `badInverseTrig` (`sin⁻¹`/`cos⁻¹` outside −1..1), `tanUndefined` (`tan 90°`, `tan π/2`), `badFactorial` (`2.5!`, `(-3)!`), `invalidExpression` (malformed, NaN). Each has `plainMessage` (sober reason, used as the screen-reader label) and `messages`: a pool of 3-5 fun lines shown in the hero numerals. **Lines must be CAPITALS (Bebas has no lowercase) and ≤ 19 characters** (a test enforces both). **How an error is shown** (so it never passes for a result): the line is set much smaller than a number (`ExtrudedNumber.maxFontSize` 60 instead of 200) with a shallow block (depth × 0.4), both applied in `numeral_animator.dart` when `hasError`; and `calculator_screen.dart` puts `plainMessage` under it in small Inter (`ValueKey('error-reason')`, 54 px below centre). No warning colour is used. **Punchlines**: `CalcError.punchlines` marks lines that are an innocent-sounding setup (**every overflow line is one**, 14 of them in `_overflowSetups`: IT WON'T FIT, THAT'S HUGE, … IT'S OUT OF HAND; the old TOO BIG TO FIT / THICC lines were dropped by the owner); `_showError` sets `CalculatorState.errorPunchline` (not carried by `copyWith`) and the screen shows `kThatsWhatSheSaid` first, right under the setup (italic w600 accent Inter 15, `ValueKey('error-punchline')`, no underline: owner found it ugly), then the plain reason below it so the joke still makes sense. 1 s after the line appears (after the error sound), `CalculatorScreen` plays `AppSounds.thatsWhatSheSaid()` (`assets/sounds/twss.mp3`, owner-supplied voice clip, centred, no pitch drift; boosted 14 dB with a limiter to mean −15 dB / peak −1.3 dB, a bit under the key sounds' −7 dB mean, because the original was ~19 dB quieter); the `ref.listen` is keyed on the punchline line and its `_punchlineTimer` is cancelled by any key before then; screen readers still get `plainMessage`. The evaluator throws `CalcException(error)`. Not errors, silent by design: the 15-digit and 60-token limits, `=` on a dangling `sin(`.

**`token.dart`**: `TokenType {number, plus, minus, multiply, divide, percent, power, leftParen, rightParen, function, constant, factorial}`. `Token(type, text)` with `==`/hashCode. Helpers: `isOperator` (+ − × ÷ ^), `isNumber`, `isPercent`, `isOpener` (leftParen or function), `endsOperand` (number, percent, rightParen, constant, factorial), `functionName` (text minus trailing `(`; function token text includes the `(`, e.g. `sin(`). Operator symbols: `+`, `-` (ASCII hyphen on the keypad's token), `×`, `÷`, `^`.

**`expression.dart`**: tokens (committed) + `currentNumber` (string being typed, e.g. `-`, `0.`, `-12.5`). Limits: `maxDigitsPerNumber = 15`, `maxTokens = 60`. Key rules:
- `appendDigit`: no-op at limits; `0`→digit replaces; `-0`→`-d`. `appendDecimal`: one dot; empty → `0.`.
- `appendOperator`: commits number (drops trailing `.`); consecutive operator replaces previous; after `endsOperand` appends; at start or after an opener only **minus** is accepted and becomes `currentNumber = '-'` (negative number). Otherwise returns `this`.
- `appendOpener` (`(`/`sin(`), `appendRightParen` (needs `openParenDepth > 0` and an operand before), `appendConstant`, `appendFactorial` (needs operand, not after `%`), `appendPowerOf('10')` (inserts `×` if after an operand, then `10`, `^`), `appendPercent` (only after a number). All go through `_committedTokens()` which turns a lone `-` currentNumber into a minus token (`-sin(30)`, `-π`) and strips a trailing `.`.
- `toggleSign` (current number or last number token — moves it back into currentNumber), `backspace` (char by char; `-` alone clears; non-number token removed), `replaceTokenAt`, `removeTokenAt`, **`removeTokenCleanly`** (number takes its `%` and one neighbouring operator with it; removing an operator between two numbers joins them: `10 × 11` → `1011`), `insertTokenAfter`.
- `fromTokens` (last number token becomes `currentNumber`), `fromResult`, `clear`, `toDisplayString` (operators spaced ` + `, but `^` and unary minus unspaced).
- `canEvaluate`, `getAllTokens()` (tokens + currentNumber as a number token).

**`parser.dart`** — grammar, lowest→highest: `expr → term (± term)*`; `term → unary (× ÷ or implicit × unary)*`; `unary → '−' unary | power`; `power → postfix ('^' unary)?` (right-assoc; `-2^2 = -4`; `2^3^2 = 512`); `postfix → primary '!'*`; `primary → number '%'? | constant | '(' expr ')' | function expr ')'`. `Parser.parse(tokens, {tolerant = true})`: tolerant trims trailing operators and dangling openers (live preview, `2 × sin(`); **in both modes unclosed `(` are auto-closed** and a stray `)` returns null; leftover tokens (e.g. `5 3`, `5 % 3` after token edits) → null (malformed, never silently dropped). Implicit multiply: next token is an opener or constant (`2π`, `2(3)`, `(1)(2)`, `2sin(30)`), or a number directly after `)`/constant/`!`. Two bare numbers stay malformed.

**`evaluator.dart`**: `Decimal` exact base-10; division via `Rational` → `scaleOnInfinitePrecision: 32`. `AngleUnit {degrees, radians}` (`fromName`). Percent semantics depend on the neighbour (**but when the left side is itself a percentage, `_isPercentage`, percentages just add: `1% − 1%` = 0, `50% + 10%` = 0.6**): `a + b%` = `a + a·b/100`, `a − b%`, `a × b%` = `a·b/100`, `a ÷ b%` = `a ÷ (b/100)`, `a ^ b%` = `a^(b/100)`; a lone `b%` = `b/100`. Powers: integer exponents exact (`Rational.pow`) **only while `base.scale × |n| ≤ 200`**; beyond that `_roundedPower` (square-and-multiply, 40 significant digits per step) — exact powers of a 32-dp quotient froze the UI (`(1+0.055÷365)^365`, ANR on 1.5.0); fast-fail estimate first (`> 1000` digits → overflow, `< −1000` → 0), `0^neg` → divideByZero, `±1` base shortcut; fractional exponent via `dart:math` and a negative base → domainError. Factorial: non-integer/negative → domainError, `n > 450` → overflow. Functions: `sin cos tan sin⁻¹ cos⁻¹ tan⁻¹ ln log √ ∛` (`log` = log₁₀). **√ and ∛ are exact-decimal Newton roots** (`_root`, 32 dp; a double root showed √2 × √2 = 2.00000000000001); the trig/log functions still go through doubles. **Degree trig reduces exactly mod 360 and special-cases multiples of 90** so `sin 180 = 0`, `tan 90` = domainError; radian results with |v| < 1e-15 snap to 0; `cos|<1e-15|` for tan → domainError. Double results go through `_fromDouble` = `toStringAsPrecision(15)` (NaN → domainError, ∞ → overflow). Constants `pi`, `e` are 33-digit Decimals.

**`formatter.dart`**: `NumberFormatter.format(Decimal)` — 15 significant digits max, **rounds** (not truncates; `1÷3×3 = 1`), commas every 3, trims trailing zeros, `-0` → `0`, integer part > 15 digits → scientific `1.5e20` (mantissa 6 dp, computed from the exact decimal so it never hits `Infinity`); a value that rounds up past 15 digits (`999…9.9`) also goes scientific (`1e15`). **|x| < 0.000001 → `_scientificSmall`** (`1.234e-15`; since 1.5.2, they used to round to "0"). `loadExpression` keeps `1e-23` as one number token (`e-` + digit). `formatInputNumber(raw)` adds commas while typing (keeps `.`/`-`; empty → `0`).

## Calculator state & controller

`CalculatorState` (`calculator_state.dart`): `expression`, `expressionText` (display string), `resultText` (hero number, default `'0'`), `previewText?`, `error?` (CalcError), `justEvaluated`, `editingTokenIndex?`, `isReplacingEditedToken`, `celebrationId` (++ on every successful `=`; triggers the pop/burst). `isZeroState` = idle `0` (hero drawn dim). `copyWith` uses `clearPreview` / `clearError` / `clearEditingTokenIndex` flags (pass `true` to null a field).

`CalculatorController` (`calculator_controller.dart`, 744 lines, the biggest logic file); `calculatorProvider` wires `onHistoryAdded` → `historyProvider.addEntry`, `angleUnit` → `settingsProvider.angleUnit`, and re-previews when the angle unit changes. Public API used by UI: `onDigit`, `onDecimal`, `onOperator(type, symbol)`, `onPercent`, `onToggleSign`, `onBackspace`, `onClear`, `onEquals`, `selectToken(i)` / `deselectToken()`, `loadResult`, `loadExpression(exprStr, result)`, `refreshPreview`, the hooks `onDivideByZero` / `onTanUndefined` (hunt), and the scientific set `onOpener(Token)`, `onRightParen`, `onConstant(sym)`, `onFactorial`, `onSquare` (`^2`), `onExpE` (`e^`), `onExp10` (`10^`).

Behaviours worth knowing:
- After `=` (`justEvaluated`): a **digit/decimal/opener/constant** starts a fresh expression; an **operator, %, +/−, !, x²** continue from the displayed answer (`_baseExpression()` = `Expression.fromResult(resultText)`). `onEquals` is ignored when already evaluated (no duplicate history/celebration). Backspace after `=` clears.
- `onEquals`: first **drops trailing operators** (and a lone `-` currentNumber), so `99 + 66 +` `=` gives 165 and the expression line/history show `99 + 66` without the hanging operator (state `expression` is replaced by the trimmed one); nothing left → no-op. Then strict parse; a dangling opener (`sin(`) is ignored quietly, any other malformed expression shows `invalidExpression`. Success adds to history, sets `justEvaluated`, `celebrationId + 1`. `_showError` picks one of `error.messages` at random (injectable `Random` in the constructor), never the same line twice running, and clears editing/preview.
- Live preview (`_computePreview`): needs ≥ 2 tokens, tolerant parse; stored in `previewText` always, but only *shown* when `settings.showLivePreview`.
- **Token editing** (tap a token in the expression line): `selectToken` sets `editingTokenIndex`, `isReplacingEditedToken = true`, hero shows the token. First digit replaces the token; later digits extend (cap 15 digits). **Backspace trims one digit even right after selecting** (since 2026-10-20; it used to delete the whole number), after which digits append (9999 ⌫ 0 → 9990); backspacing the last digit removes the number cleanly and drops the highlight. **Digits and `.` on a highlighted operator/percent/bracket/function are ignored** (since 2026-10-20; they used to turn it into a number, leaving `9999 9999` side by side → "THAT'S NOT MATH" and garbled edits after). Operator on a highlighted operator/percent replaces it; on a highlighted number swaps the *following* operator or inserts one after. `%` on a number inserts a percent token after it (selection moves to it); on an operator it is ignored. Backspace on a selected operator/percent → `removeTokenCleanly`. `_applyAdvanced` first calls `deselectToken()`.
- `loadExpression` (history tap) re-tokenises the saved display string by hand: numbers `[0-9.,]` (+ `e` only when a digit follows, so `1.5e20` stays one token and `2e` is number+constant), operators `+ − - × * ÷ /`, `%`, `^`, parens, `!`, `π`/`e`, and function names from `_functionNames`. **Add any new function name to `_functionNames`** or history restore breaks.

## Audio (`core/audio/app_sounds.dart`)

Static `AppSounds` on `flutter_soloud` 4.x: all sounds decoded up front, `play` is synchronous (low latency, overlapping presses OK), buffer 1024 frames, 32 voices, media stream, no audio-focus (music keeps playing). Silent no-op until `init` succeeds (tests never touch the engine). `Sfx` enum: `digit0..9, operator, utility, backspace, clear, success, error` + scientific `trig, log, power, root, bracketOpen, bracketClose, constant, factorial, shiftOn, shiftOff` (file name = snake_case; `digit_N`). `_folder = _material ?? _pack.name`; selectable packs stay loaded, material folders lazy-load (`setMaterial`), `previewMaterial(folder, sfx)` for the store demo, `previewPack`. Pitch: digits/melodic/success exact; others ±4 % drift; backspace winds down 3 %/press within 600 ms (floor 0.8). `_gain = volume × 0.4` (files are mastered loud). Shared outside the packs: `twss.mp3` (`AppSounds.thatsWhatSheSaid()`, the overflow punchline, not generated), `launch.wav` (copy of typewriter `clear`, `AppSounds.launch()`), `detent.wav` (`AppSounds.detent(up:)`, converter notches, 40 ms throttle). `playWhenReady` queues a sound requested before load (TTL 1.2 s). `panned(pan, fn)` positions the sound in stereo. **Background**: `main.dart` hooks an `AppLifecycleListener` (`onHide: AppSounds.suspend`, `onShow: AppSounds.resume`): `suspend` deinits SoLoud and drops every source (an open output stream kept PopCalc listed in the phone's per-app volume panel while in the background), `resume` re-inits and reloads (`_generation` makes loads from the old engine discard their results).

**Where sound plays**: keypad keys, scientific tray keys, converter keypad, answer (`success`) / error, launch, converter detents. Toggles, settings, DEG/RAD and converter taps are **haptics only**. Volume slider preview = `digit7`; sound toggle preview = `success`.

**Generation**: `tool/generate_sounds.py` (pure-Python synthesis, deterministic seeds: `Random(42)` for the 3 packs, `100+k` per material, `9` detent). Re-run rather than hand-editing WAVs. Output must keep identical file names per folder; `test/core/sound_files_test.dart` and `test/materials_test.dart` assert completeness. New folders must be listed under `flutter.assets` in `pubspec.yaml`.

## Haptics (`core/haptics/app_haptics.dart` + `PopCalcActivity.kt`)

Static `AppHaptics` (`enabled`, `strength`, `feel`). Each call builds `List<_Hit(primitive, scale, delayMs)>` and sends `MethodChannel('popcalc/haptics').invokeMethod('play', {hits:[{p,s,d}], strength})`; Dart falls back to Flutter `HapticFeedback` if the native call returns false/throws (and then stops trying). Kotlin: Android 11+ composed primitives (`click tick lowTick thud quickRise slowRise quickFall spin`; unsupported primitives are swapped for the nearest cousin), else a waveform of amplitude-scaled pulses (min amplitude 60), else a plain vibrate; `boost(x) = x^0.8 × 1.1` lifts weak motors. **Adding a primitive means editing both Dart and `PopCalcActivity.kt`.** Vocabulary: `selectionClick`, `lightImpact`, `mediumImpact`, `heavyImpact`, `digit`, `operatorKey`, `utility`, `backspace`, `clear`, scientific (`trig log power root bracketOpen bracketClose constant factorial`), `shift(on)`, `mode(on)`, converter (`swap category unitPick detent detentEnd`), `success`, `error`, `demo(feel)`. The four everyday keys are overridden by the active `HapticFeel`.

## Gotchas & conventions

- **Launcher aliases**: never rename or remove the `.MainActivity` alias, and keep exactly one alias enabled in the manifest; `flutter run` launches through it.

- **Edge-to-edge** (Android 15+ forces it for target SDK 35+; Flutter 3.47 targets 36). `PopCalcActivity.enableEdgeToEdge()` (called before `super.onCreate`) does what androidx's `EdgeToEdge.enable` does, without androidx (FlutterActivity is no ComponentActivity, and the project has no androidx dependency): `setDecorFitsSystemWindows(false)` (or the old layout flags), cutout mode ALWAYS/SHORT_EDGES, no contrast scrims. It deliberately avoids the deprecated `setStatusBarColor`/`setNavigationBarColor` (they trigger Play's other edge-to-edge warning); bar colours stay in Dart (`main.dart`: `SystemUiMode.edgeToEdge` + transparent bars). This answers Play Console's "Edge-to-edge may not display for all users" recommendation. insets are handled in Dart: full screens and `StoreSheet`/`_UnitSheet` use `SafeArea`, and the settings and history sheets add `MediaQuery.viewPaddingOf(context).bottom` to their scroll padding. **Any new screen or bottom sheet must do one of the two**, or its last row sits under the navigation bar. Play Console shows a generic "Edge-to-edge may not display for all users" notice for every app targeting 35+; it is advice, not a blocker.

- **Never rewrite files with PowerShell 5.1 `Get-Content … | Set-Content`**: it reads UTF-8 as ANSI and writes it back garbled (`—` → `â€”`) with a BOM. Use the Edit tool. (Happened on 2026-10-20 with README, pubspec and settings_sheet; repaired by re-encoding.)
- State classes use `copyWith` with explicit `clearX` booleans for nullable fields; follow that pattern.
- `AppSounds` / `AppHaptics` are static singletons, deliberately fire-and-forget; wrap UI taps with them rather than awaiting.
- Comments in this codebase explain *why*; keep that voice, don't narrate what.
- Premium gating always goes through `ownsSkin`; never compare product ids directly in UI.
- Money is shown only as Play wrote it (`prices`), never hardcoded or formatted by the app; use `moneyLike` for totals.
- `ThemeNotifier.toggleTheme` (ink↔sunny) exists but the UI picks skins through `setTheme`.
- The minus *token* text is an ASCII `-` while the keypad key shows `−`; `loadExpression` accepts both.
- Heavy paint: the extruded numeral stamps up to 64 TextPainters per frame; keep new per-frame work out of it and respect `isLite`.
- The accelerometer subscription lives in every `AnimatedExtrudedNumber` (calculator hero and converter input).
- `architecture.md` mentions a theme picker, golden tests and `app/` folder that were not built as written.
